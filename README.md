# 🌊 바다 (BADA) : 점수 받아

> **혼자 공부하는 학생들을 위한 무료 내신 영어 학습 웹앱**  
> 목표를 향해 항해하는 **'바다'**이자, 노력한 만큼 **'점수 받아'** 간다는 뜻을 담았습니다.

---

## 🎯 제작 목적 (Why)

학원이나 유료 자료 없이 혼자 내신 영어를 준비할 때 겪는 두 가지 막막함을 해결하기 위해 만들었습니다.

1. **변형 문제 부족**: 같은 지문을 여러 각도로 연습할 문제가 턱없이 부족한 문제
2. **서술형 첨삭의 어려움**: 어구 배열, 주제문·요약문 작성처럼 혼자 풀고 채점하기 막막한 서술형 대비

별도의 회원가입이나 유료 API 결제 없이, 학생 누구나 자신이 쓰는 무료 AI(ChatGPT, Gemini, Claude)와 연결해 문제를 만들고 피드백받을 수 있도록 설계했습니다.

---

## ✨ 주요 기능

- **12가지 내신 실전 유형 지원**
  - 객관식: 주제, 제목, 어휘, 어법, 빈칸, 순서, 문장 삽입, 요약, 무관한 문장, 함축의미 추론
  - 서술형 및 학습 도구: 어구 배열, 주제문·요약문 작성, 백지 지문, 지문 분석(S/V/수식어구)
- **3단계 난이도 조절**: 쉬움 · 보통 · 어려움 난이도별 맞춤 학습
- **무료 AI 연동 (No-API 구조)**: 별도 API 키 발급 없이 클릭 한 번으로 프롬프트를 복사해 내 AI에서 새 문제를 생성하고, 결과(JSON)를 붙여넣어 바로 풀이
- **풀이 기록 관리**: 푼 문제와 오답·피드백을 브라우저에 자동 저장해 복습 지원

---

## 📖 사용 방법 (How to Use)

### 1. 기본 문제 풀기
1. 상단 **`연습`** 또는 **`문제 세트`** 탭에서 원하는 지문과 유형, 난이도를 선택합니다.
2. 문제를 풀고 바로 정답과 해설, 서술형 피드백을 확인합니다.

### 2. 내 AI로 새 문제 추가하기 (`AI 출제` 탭)
1. **`AI 출제`** 탭에서 사용 중인 AI(**ChatGPT / Gemini / Claude**)와 원하는 유형·난이도를 고릅니다.
2. **`프롬프트 생성 및 복사`** 버튼을 누른 뒤, AI 채팅창에 붙여넣어 실행합니다.
3. AI가 만들어 준 JSON 답변을 그대로 복사해 앱의 **`JSON 가져오기`** 칸에 붙여넣으면 즉시 새로운 문제 세트로 풀 수 있습니다.
   *(※ AI 답변이 코드 블록처럼 보여도 정상입니다.)*

### 3. 복습하기
- **`풀이 기록`** 탭에서 지금까지 푼 지문과 결과를 다시 확인할 수 있습니다.

## 🗺️ 향후 계획 (Roadmap)

- **1단계**: 학교 파일럿 배포 및 실제 학생 피드백 기반 기능 개선
- **2단계**: 사진/PDF 지문 인식 및 출제 포인트 자동 분석 파이프라인 고도화
- **3단계**: 누구나 과목별 문제 팩을 얹어 쓸 수 있는 **전 과목 무료 오픈소스 학습 엔진**으로 확장

---

## ⚠️ 저작권 및 데이터 안내

- 본 서비스는 **비상업적 무료 학습 도구**입니다.
- 사용자의 학습 기록과 추가한 문제는 **브라우저 내부(`localStorage`)에만 저장**되며 외부 서버로 전송되지 않습니다.
- 공개 저장소에는 저작권이 있는 학교 프린트나 모의고사 원문을 포함하지 않으며, 학습 엔진 구조와 예시 데이터만 제공합니다.
